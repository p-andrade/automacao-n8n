# Miniestudo: Automação com n8n

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO
com o objetivo de explorar o uso da Inteligência Artificial como
ferramenta de aprendizagem ativa.

O tema escolhido foi:

**Automação com n8n**

O estudo utiliza curadoria de fontes, engenharia de prompts,
análise crítica e organização do conhecimento.

---

## 🎯 Objetivos

- Compreender os fundamentos do n8n
- Entender a estrutura de workflows
- Estudar triggers, nodes e integrações
- Explorar webhooks e APIs
- Entender tratamento de erros
- Identificar boas práticas de segurança
- Criar exemplos práticos de automação
